Quick Answer

The Web Designing course in Nagpur covers design fundamentals, colour theory, typography, Figma wireframing and prototyping, responsive layout, HTML/CSS implementation of designs, and accessibility standards. It is designed for students and working professionals who want to become UI/UX designers, frontend designers, or design-aware developers — and produce a portfolio of case studies that demonstrates real design thinking.

Week-by-Week Syllabus — Web Designing

7 modules · 8 weeks (64 hours of instruction)

Module 1Design Fundamentals & Visual Principles

Week 1
  • Gestalt principles: proximity, similarity, continuity, closure, figure/ground
  • Visual hierarchy: size, weight, contrast, spacing, and position
  • Negative space and white space as a design element
  • Grid systems: 8-point grid, 12-column layouts, baseline grids
  • Colour theory: hue, saturation, value, warm vs cool, colour harmony models
  • WCAG colour contrast requirements: 4.5:1 for text, 3:1 for large text
  • Design critique vocabulary and how to give and receive design feedback
Figma (free tier)PinterestBehance

Outcome: Analyse any website or app design using Gestalt principles, visual hierarchy, and colour harmony — and articulate why it works or fails.

Module 2Typography for Screen Design

Week 2
  • Type anatomy: serif, sans-serif, monospace, display — when to use each
  • Typographic scale: establishing a fluid type scale for heading/body hierarchy
  • Line height, letter spacing, paragraph width, and reading comfort
  • Font pairing strategies: contrast vs harmony, max 2–3 typefaces per project
  • Loading web fonts: Google Fonts, next/font, and font performance
  • Variable fonts and how they affect responsiveness and file size
  • Typography audit: analysing real Nagpur business websites for type issues
FigmaGoogle FontsType Scale tool

Outcome: Establish a typographic system for a design project — choosing typefaces, scaling sizes, and setting spacing rules that ensure readability across screen sizes.

Module 3Figma — Wireframing & Component Design

Weeks 3–4
  • Figma interface: frames, layers, groups, components, and the properties panel
  • Low-fidelity wireframing: user flows, information architecture sketching
  • Auto Layout: responsive frames that resize automatically across screen sizes
  • Components and variants: building a design system with button states, input fields, cards
  • Styles: colour styles, text styles, and effect styles for consistency
  • Real content: why you should never use Lorem Ipsum in production wireframes
  • Design handoff: inspect panel, measuring spacing, exporting assets
FigmaFigJamFigma Auto LayoutFigma Variants

Outcome: Build a 10-screen wireframe in Figma using Auto Layout, variants, and a shared component library — structured for developer handoff.

Module 4Prototyping & User Flow

Week 5
  • Figma prototype mode: connections, triggers, animations, overlays
  • User flow mapping: from business requirement to screen-by-screen decision tree
  • Interaction types: on click, on hover, after delay, drag, scroll
  • Micro-interactions: loading states, empty states, success/error feedback
  • Presenting prototypes: sharing links, commenting, and stakeholder feedback
  • Usability testing basics: 5-second test, think-aloud protocol, Maze setup
  • Iteration: how to process feedback and update designs without losing history
Figma Prototype modeMaze (usability testing)Loom

Outcome: Create an interactive prototype in Figma that demonstrates a complete user flow — from landing to task completion — with micro-interactions and shareable link.

Module 5Responsive Layout & HTML/CSS Implementation

Week 6
  • Translating Figma designs to semantic HTML structure
  • CSS Flexbox and Grid: pixel-perfect implementation of design layouts
  • Tailwind CSS utility classes: matching Figma spacings to utilities
  • Responsive breakpoints: mobile-first CSS with media queries
  • CSS custom properties: implementing a design token system in code
  • Image optimisation: WebP/AVIF, appropriate sizing, lazy loading
  • Matching designs across browsers: browser developer tools inspection
HTML5CSS3Tailwind CSSChrome DevTools

Outcome: Convert a Figma design into pixel-accurate, responsive HTML/CSS that passes cross-browser inspection and matches the original at all three breakpoints.

Module 6Accessibility & Inclusive Design

Week 7
  • WCAG 2.2 accessibility principles: Perceivable, Operable, Understandable, Robust
  • Semantic HTML as the first layer of accessibility
  • ARIA attributes: roles, states, properties — when to use and when to avoid
  • Keyboard navigation: tab order, focus management, skip links
  • Screen reader testing: VoiceOver on Mac, NVDA on Windows, mobile screen readers
  • Accessible colour contrast and designing for colour blindness
  • Automated audit with axe DevTools, WAVE, and Lighthouse Accessibility score
axe DevToolsWAVEVoiceOver / NVDALighthouse

Outcome: Audit a design for WCAG 2.2 AA compliance, fix identified issues, and achieve a Lighthouse Accessibility score of 95+ on the implemented HTML page.

Module 7Portfolio Case Studies & Presentation

Week 8
  • What makes a design case study: problem, research, process, solution, outcomes
  • Writing case study copy: STAR format adapted for design portfolio
  • Presenting your capstone project as a portfolio piece
  • Building a simple portfolio site on GitHub Pages or Carrd
  • Publishing to Behance: thumbnail, title, tags, project description
  • Preparing a Figma portfolio link suitable for job applications
  • What design interviewers actually look for: process over polish
FigmaNotion / CanvaGitHub PagesBehance

Outcome: Publish a structured design portfolio case study with documented process, Figma prototype link, and implemented code — ready to share with recruiters.

Frequently Asked Questions — Web Designing

Is web designing a good career in Nagpur in 2026?
Yes. UI/UX design is one of the fastest-growing roles in Indian tech. Every product company, startup, and digital agency needs designers. Nagpur's growing IT sector has consistent demand for UI/UX talent. Web designing also enables freelancing — Nagpur businesses are actively looking to improve their online presence, and a skilled designer with a portfolio can find clients locally.
What is the fee for the Web Designing course in Nagpur?
Fees are shared during a personal advisor call along with batch options. WhatsApp our team or fill the enquiry form — an advisor will share the complete fee breakdown and EMI options within one working day.
Do I need to know coding to join the Web Designing course?
No prior coding is needed to join. Weeks 1–5 are focused on Figma and design principles — zero code involved. Weeks 6–7 introduce HTML/CSS so you can implement your designs, which makes you far more hireable. Basic code knowledge helps you communicate more effectively with developers.
Does this course teach Figma?
Yes. Figma is the primary design tool throughout the course. You learn the Figma interface, Auto Layout, Components and Variants, prototype mode, and the design-to-developer handoff workflow — the exact tools used by professional UI/UX designers at product companies today.
Is this course available offline in Nagpur?
Yes. Offline classes at our Wardha Road centre in Nagpur. Online live Zoom and hybrid options are also available. Weekend batches run Saturday–Sunday 9 AM–1 PM for working professionals.
Will I have a portfolio after completing this course?
Yes. Week 8 is dedicated entirely to building and publishing your design portfolio. You graduate with at least one detailed case study published on Behance and GitHub Pages, with a Figma prototype link — the standard portfolio format expected by UI/UX hiring managers.
Can a non-technical arts or commerce student learn web designing?
Absolutely. Web designing favours visual sensibility and creative thinking over technical background. Many of the best UI/UX designers come from non-technical backgrounds. The course is structured for zero prerequisites — your ability to observe, think visually, and iterate based on feedback matters more than any prior degree.
What is the difference between UI design and UX design?
UI (User Interface) design focuses on how things look — colours, typography, components, and visual hierarchy. UX (User Experience) design focuses on how things work — user flows, information architecture, usability, and reducing friction. This course covers both, as modern designers are expected to handle the full process from wireframe to visual implementation.
