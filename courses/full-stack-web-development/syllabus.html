Module-by-Module Curriculum

Module 1:HTML5 & Semantic Web Structure

Week 1

Core Topics

  • HTML5 document structure: DOCTYPE, head, body, meta tags
  • Semantic elements: header, nav, main, article, section, aside, footer
  • Text content: headings, paragraphs, lists, links, emphasis
  • Forms: input types, labels, form validation attributes, textarea, select
  • Multimedia: images (alt text, srcset), audio, video, iframe
  • Accessibility basics: ARIA roles, landmark regions, keyboard navigation

Tools & Tech

VS CodeLive Server extensionChrome DevTools

Learning Outcomes

  • Write fully semantic, accessible HTML5 pages that screen readers and search engine crawlers can understand correctly.

Module 2:CSS3 & Tailwind CSS — Layout & Design

Week 2

Core Topics

  • CSS selectors, specificity, cascade, and inheritance
  • Box model: padding, margin, border, box-sizing
  • Flexbox: flex-direction, justify-content, align-items, flex-wrap
  • CSS Grid: grid-template-columns, areas, auto-fit/auto-fill
  • Responsive design: media queries, mobile-first methodology
  • Tailwind CSS utility classes: spacing, typography, colour, layout
  • CSS custom properties (variables) and dark mode strategies
  • Animations: transitions, @keyframes, transform, animation shorthand

Tools & Tech

CSS3Tailwind CSS v3FlexboxCSS Grid

Learning Outcomes

  • Build a fully responsive, multi-section landing page using CSS Grid, Flexbox, and Tailwind utilities that works across mobile, tablet, and desktop.

Module 3:JavaScript — Interactivity & DOM

Week 3

Core Topics

  • JavaScript fundamentals: variables, data types, operators, control flow
  • Functions: declarations, expressions, arrow functions, closures
  • Arrays and objects: methods, destructuring, spread/rest operators
  • DOM manipulation: querySelector, createElement, event listeners
  • Asynchronous JS: setTimeout, Promises, async/await, try/catch
  • Fetch API: GET and POST requests, JSON parsing, error handling
  • Local Storage: reading, writing, and removing data

Tools & Tech

Vanilla JavaScriptChrome DevTools ConsoleFetch API

Learning Outcomes

  • Add dynamic interactivity to web pages using DOM events, Fetch API calls to public APIs, and Local Storage persistence — no framework needed.

Module 4:React — Building UI Components

Week 4

Core Topics

  • Why frameworks: component reusability, virtual DOM, declarative UI
  • Vite project setup: file structure, JSX syntax, hot module reload
  • Functional components, props, and component composition
  • useState for local state, useEffect for side effects
  • React Router: Link, NavLink, useNavigate, dynamic routes
  • Fetching API data in useEffect with loading and error states
  • Deploying a React app to Vercel in under 5 minutes

Tools & Tech

React 18ViteReact Router v6React DevTools

Module 5:Node.js & Express — Backend Fundamentals

Weeks 5–6

Core Topics

  • How the web works: HTTP request-response cycle, DNS, TCP/IP basics
  • Node.js runtime: module system, file system, built-in modules
  • Express app setup: routes, controllers, middleware, error handling
  • Building CRUD REST API endpoints: Create, Read, Update, Delete
  • Environment variables with dotenv and config management
  • SQL database (MySQL / SQLite): tables, CRUD queries, JOIN operations
  • NoSQL database (MongoDB): documents, collections, basic queries
  • Connecting both SQL and MongoDB to an Express app
